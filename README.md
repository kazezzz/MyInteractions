# MyInteractions

A Unity scene with five interactive elements.

## Unity version
6000.6.2f1

## How to run
Open the project in Unity, open Assets/Scenes/SampleScene.unity,
and press Play. Click the Game view before using keyboard controls.

## Interactions
1. Press 1 to switch the cube between red and blue.
2. Press 2 to start or stop the other cube rotating.
3. Press Space to make the ball jump. Wait until it lands to jump again.
4. Click Help to show or hide the instructions panel.
5. Press M to play a short melody. Press again to restart it.
